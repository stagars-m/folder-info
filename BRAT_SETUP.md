# BRAT setup

## Repository

Create a public GitHub repository named `folder-info` and upload the contents of this source repository package.

## Release

Create a GitHub release with:

```text
Tag: 1.0.0
Title: Folder Info 1.0.0
Target: main
```

Attach these files individually from the release-assets package:

```text
main.js
manifest.json
styles.css
```

## Obsidian

In BRAT, add:

```text
https://github.com/stagars-m/folder-info
```

Then enable **Folder Info** under Community plugins.
